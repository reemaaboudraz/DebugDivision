## How to run 
- Prerequisites
  - Java 17 (JDK)
  - Node.js
    
1. Start the backend `backend/ticket-backend/src/main/java/TicketBackendApplication.java`
    ```bash
    cd backend/ticket-backend
    chmod +x mvnw #only needed once if permission denied
    ./mvnw spring-boot:run
    ```
2. Start the frontend (new terminal)
    ```bash
    cd frontend
    npm install
    npm run dev
    ```
